Prompt for Claude Design

Design "Deskmates" (working name, formerly Agent Board), a Mac dashboard that shows many Claude AI agents as friendly little characters at desks. The user dislikes reading, so every status must be shown by the character's pose, motion and color, not by text. 1. Character set: one base "buddy" (a soft rounded blob with two big eyes) in 6 states: working (typing, gently bobbing, small tool icons popping out), needs you (hand raised, waving, amber glow), done (happy closed eyes, green check), asleep (eyes shut, zzz, desaturated), tired (droopy eyes, sweat drop, red low battery), stuck (looking around, question mark). Give 6 body colors. 2. Main screen at 1440px wide: a top "Now" bar with big counters (needs you, working, done, asleep) and two ring gauges per Claude account (5-hour and weekly usage). Below, "rooms": Work, Personal and Chrome, each with agent tiles (buddy, 2-word name, project dot, battery for context size, day squares for age). A right-side drawer for a selected agent: 4 icon counters (files, commands, pages, helpers), one-sentence latest update, 4 big buttons (Open preview, Jump to tab, Fresh start, Delete). 3. A tiny menu-bar version and a full-screen TV mode. 4. Two extra skins using the same 6 states: little robots (Bots) and glowing orbs (Orbs). A small badge on each character shows where the agent runs: terminal (>_), desktop app, or Chrome. 5. A logo and app icon for the name Deskmates. 6. Light and dark themes. Playful and warm, but clean enough for a professional tool. Not childish. Minimal words: icons and numbers first.
